# Duo – zusammen fitter

Fitness-Challenges für zwei: tägliche und wöchentliche Challenges, Duelle, geführte Workouts mit dem eigenen Körpergewicht, Essensvorschläge und eine gemeinsame Einkaufsliste.

- Web-App (PWA), läuft auf Android und iPhone
- Sync über eine eigene Supabase-Datenbank, die Verbindung wird beim ersten Start eingerichtet (nichts davon steht im Code)
- **Ende-zu-Ende-verschlüsselt** (AES-256-GCM): Inhalte werden auf dem Gerät verschlüsselt, der Server sieht nur unlesbare Daten

Demo: `?demo` an die Adresse anhängen.
